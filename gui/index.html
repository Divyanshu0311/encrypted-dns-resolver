Asks every resolver the same question twice: first with an empty cache, then again. Shows what forwarding, recursion and caching each cost.

Sends many queries through the full middleware path (rate limiter → coalescing → workers → cache → upstream) from 1000 simulated clients.

One client fires a burst of queries at once. The per-client rate limiter refuses the excess, and repeated offences get the client blocked.

Makes a share of lookups fail inside the workers. After enough failures in a row a worker's circuit breaker opens, rests, then lets one probe query through.

Watch the Workers panel: breakers go open, then half-open, then closed again once you set the rate back to 0%.
